# QA-005: Missing static assets return the HTML app shell

|            |                                            |
| ---------- | ------------------------------------------ |
| Severity   | Minor                                      |
| Area       | Hosting, caching                           |
| Status     | Open                                       |
| Tracked by | `tests/e2e/known-defects.spec.ts` (QA-005) |

## Steps to reproduce

1. Request `/assets/<random>.js`.

## Expected

`404 Not Found`.

## Actual

`200 OK` with `index.html`. The catch-all rewrite also matches asset paths. After a deploy, a browser holding a stale page requests an old hashed bundle and receives HTML, which the browser cannot execute, so the page can break until a hard refresh.

## Suggested fix

Exclude `/assets/` (and file extensions) from the SPA rewrite so missing files return a real 404.
