# QA-007: Landing page buttons have accessible names that omit their visible text

|            |                                            |
| ---------- | ------------------------------------------ |
| Severity   | Minor (accessibility)                      |
| Area       | WCAG 2.5.3 Label in Name                   |
| Status     | Open                                       |
| Tracked by | `tests/e2e/known-defects.spec.ts` (QA-007) |

## Actual

Five controls on `/` have an `aria-label` that does not contain the text shown on the button. Voice-control users who say the text they see cannot activate them by name.

## Suggested fix

Remove the `aria-label` where the visible text is already descriptive, or make the label start with the visible text.
