# QA-004: Gallery error exposes a status code and is not localised

|            |                                            |
| ---------- | ------------------------------------------ |
| Severity   | Minor                                      |
| Area       | Error messages, i18n                       |
| Status     | Open                                       |
| Tracked by | `tests/e2e/known-defects.spec.ts` (QA-004) |

## Steps to reproduce

1. Open `/g/<random token>` with the Indonesian UI.

## Expected

A message in the visitor's language, with no transport detail.

## Actual

The error text includes a raw status such as "(status 404)", and part of the message ("Gallery not found") is English on the Indonesian UI. Clients of a photographer see this page, so it is customer-facing.

## Suggested fix

Map API errors to localised, human-readable copy and keep status codes out of the UI.
