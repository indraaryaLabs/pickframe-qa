# QA-003: Every unknown URL declares the home page as canonical

|            |                                            |
| ---------- | ------------------------------------------ |
| Severity   | Minor                                      |
| Area       | SEO                                        |
| Status     | Open                                       |
| Tracked by | `tests/e2e/known-defects.spec.ts` (QA-003) |

## Steps to reproduce

1. Open an unknown path.
2. Read `<link rel="canonical">` and `<meta name="robots">`.

## Expected

Either no canonical, or `noindex` on the not-found view, so crawlers do not treat arbitrary URLs as duplicates of the home page.

## Actual

The canonical points at `/` and the page is indexable. With a catch-all rewrite, every garbage URL is a soft-duplicate of the landing page.

## Suggested fix

Set `noindex` on the not-found view and omit the canonical there. Related to QA-001 and QA-005.
