# QA-002: Document title repeats the brand name

|            |                                            |
| ---------- | ------------------------------------------ |
| Severity   | Minor                                      |
| Area       | SEO, metadata                              |
| Status     | Open                                       |
| Tracked by | `tests/e2e/known-defects.spec.ts` (QA-002) |

## Steps to reproduce

1. Open an unknown path such as `/does-not-exist`.
2. Wait for the title to stop changing.

## Expected

A title that names the page once, for example "Page not found · PickFrame".

## Actual

The title settles on "PickFrame · PickFrame". The page title is built as `<page> · <brand>` and the page part falls back to the brand.

## Suggested fix

Fall back to the brand alone when no page title is set, or provide a title for the not-found view (see QA-001).
