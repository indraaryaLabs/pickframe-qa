# QA-008: Public pages scroll sideways on small phones

|            |                                                  |
| ---------- | ------------------------------------------------ |
| Severity   | Minor                                            |
| Area       | Responsive layout, WCAG 1.4.10 Reflow            |
| Status     | Open                                             |
| Tracked by | `tests/e2e/responsive.spec.ts` (`knownOverflow`) |

## Actual

| Page       | Viewport | Document width          |
| ---------- | -------- | ----------------------- |
| `/pricing` | 360px    | 385px                   |
| `/pricing` | 320px    | wider than the viewport |
| `/guide`   | 320px    | wider than the viewport |

360px is the most common Android width, so this affects real visitors. At 390px and above every page fits.

## Suggested fix

Find the element that sets the minimum width (the pricing comparison and the shared header are the first candidates) and let it wrap or scroll inside its own container.
