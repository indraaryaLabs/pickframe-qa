# QA-006: Low-contrast text on the landing, pricing and sign-in pages

|            |                                                        |
| ---------- | ------------------------------------------------------ |
| Severity   | Major (accessibility)                                  |
| Area       | WCAG 1.4.3 Contrast (Minimum)                          |
| Status     | Open                                                   |
| Tracked by | `tests/e2e/known-defects.spec.ts` (QA-006, four pages) |

## Method

axe-core 4.x with the WCAG 2.2 AA tag set, run with `reducedMotion: 'reduce'` so reveal animations do not leave text semi-transparent during the scan.

## Findings

| Page                      | Foreground                    | Background | Ratio | Needs |
| ------------------------- | ----------------------------- | ---------- | ----- | ----- |
| `/` (browser preview bar) | `#9b9b9b`                     | `#fafafa`  | 2.66  | 4.5   |
| `/` (proof copy)          | `#777777`                     | `#f3f3f3`  | 4.03  | 4.5   |
| `/pricing` (accent icon)  | `#d09b46`                     | `#f8f2e6`  | 2.22  | 3.0   |
| `/pricing` (dashed note)  | `#806f59`                     | `#f8f2e6`  | 4.34  | 4.5   |
| `/pricing` (small labels) | `#989897`                     | `#f6f6f5`  | 2.66  | 4.5   |
| `/login` (toggle label)   | `#6f6f6f`                     | `#f2f2f1`  | 4.48  | 4.5   |
| `/login?mode=register`    | same toggle label as `/login` |

## Suggested fix

Darken the affected greys and the warm brown until each pair reaches 4.5:1 (3:1 for non-text icons). The sign-in toggle is 0.02 short, so a one-step darker token is enough.
